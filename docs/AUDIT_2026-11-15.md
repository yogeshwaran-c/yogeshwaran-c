## Remaining decisions and release blockers

1. User approval of the local redesign; it must not be published automatically.
2. Known malicious setup files still exist on remote main. Local changes disable
   them; remote remediation is separate and must precede a trusted release setup.
   Revoke the corporate telemetry credential in the migration bundle separately.
3. Confirm permission/authenticity for publishing colleague quotes and whether
   availability/contact details are still current. These are existing claims,
   not independently authenticated in this audit.
4. Add detailed case studies and verified outcomes when supporting evidence is
   available. Current project cards describe implementation, not measured impact.
5. Search Console/Bing verification, cross-post backlog and uptime configuration
   are historical notes, not verified current account state.
6. CAREER_GROWTH.md contains historical suggestions and unsupported eligibility/
   compensation estimates. Do not reuse those as current personal facts.
7. Production Lighthouse, security headers, cache behavior, indexing and field
   metrics require post-deploy/account verification.
