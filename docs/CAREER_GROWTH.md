# Career Growth Roadmap

Next moves for career growth now that the platform (portfolio, blog, resume, analytics, presence) is built. Structured by time horizon, in priority order.

> **The filter:** of these 10 moves, only three will materially change the career — MVP application, interviewing, and picking a specialization. Everything else is multiplier, not accelerator.

---

## This week — activate what's built

### 1. Cross-post the first blog post
Hashnode + Dev.to + r/vscode + Twitter + LinkedIn. Until distribution happens, all the infrastructure is zero value. See [BLOG_PUBLISHING.md](./BLOG_PUBLISHING.md) for the canonical-URL setup.

### 2. Apply for Microsoft MVP
→ [mvp.microsoft.com/en-US/nomination](https://mvp.microsoft.com/en-US/nomination)

20 merged PRs to VS Code qualifies the profile today. MVP badge unlocks compounding credibility:
- Free annual Azure subscription (~$1,800/yr in credits)
- MVP Summit access (Redmond, networking with Microsoft leadership)
- Lifetime credibility signal on LinkedIn

### 3. Interview at 2-3 remote companies
Even with no intent to leave. Target companies:
- Vercel, Supabase, Stytch, PostHog, Linear
- Any YC-backed AI/infra startup

Likely underpaid 2-5× current compensation. Having one competing offer rewrites the Finstein conversation.

## Next 90 days — compound authority

### 4. Ship an owned OSS library
Not contributing — **owning**. Extract something already built at Finstein (a NestJS module for document extraction pipelines, or a DSPy-style utility). Publishing a library used by others = different credential than 78 merged PRs to other repos.

### 5. Propose NestJS CLI committer status
27 merged PRs is typically more than enough. Email Kamil Myśliwiec directly with a short pitch. Maintainer access elevates from "contributor" to "maintainer" — different tier of signal.

### 6. Second blog post
Break the one-post trap. Pick a NestJS CLI PR, use the same template from `blog/_template.html`. Maintain the cadence per [BLOG_DISCIPLINE.md](./BLOG_DISCIPLINE.md) rule #3 ("never miss twice").

### 7. Submit a conference talk
First talk is the hardest; subsequent ones get easier. Target:
- AngularCon, NodeCongress, JSConf India
- DevFest India (Google Developer Groups)
- FOSS ASIA

Angle: *"What I learned from 78+ merged PRs to major OSS."*

## Next 6-12 months — specialize and scale

### 8. Pick a specialization
Current profile is broad (full-stack + AI + OSS). Narrow + deep compounds faster. Candidates to own one phrase:
- **"Document Intelligence engineer"** — leverages Finstein work + OpenAI/Gemini experience
- **"NestJS tooling specialist"** — leverages 27 CLI PRs + committer path
- **"OSS contributor coach"** — unique angle, teachable skill, content moat

### 9. Write a deep-dive case study
The Document Intelligence platform at Finstein, published as `/case-study/document-intelligence`:
- Architecture diagram
- Decisions & tradeoffs
- Outcome metrics (hours saved, accuracy, scale)
- Code samples

Becomes THE link in every interview and job application. Drops bomb in a Staff-level interview.

### 10. Pick a career direction
One of:

| Direction | Target | Upside |
|---|---|---|
| **Staff engineer** | AI infra startup (LangChain, Pinecone, Arize) | 2-5× comp, technical depth |
| **Founding engineer** | YC-backed AI company | Equity, breadth, speed |
| **Developer Advocate** | Vercel, Supabase, NestJS-using co | OSS profile + blog = perfect fit |
| **Independent consultant** | Direct clients | ~$150-250/hr ceiling, autonomy |
| **Own product** | Document intelligence SaaS | Built it once, can do again |

---

## The three-question filter

When uncertain which of these to prioritize, ask:

1. **Going deeper** (specialize, build authority in one area)?
2. **Going wider** (new role at a better-paying company)?
3. **Going your own** (consulting or product)?

The answer to this shapes the next 90 days.
