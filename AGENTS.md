# Repository context

Read `CLAUDE.md` before working in this repository. Its branching, identity,
content consistency, resume, and release conventions apply to Codex too.
Read `docs/ASSISTANT_CONTEXT.md` for the user's ongoing workflow.
Apply `docs/PR_QUALITY_CHECKLIST.md` to every change and PR. Record actual
verification, Lighthouse results when relevant, N/A items and remaining failures.

Keep durable decisions in these tracked documents so they travel between laptops.
Update them when the user establishes a new preference; do not store credentials,
private keys, tokens, or speculative personal information.

Before editing, inspect Git status and preserve existing user changes. Do not
commit directly on main or develop. Do not publish or cross-post merely because
a date is due; follow the user's current task and the repository release flow.
