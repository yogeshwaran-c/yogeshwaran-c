# Portfolio fonts

Self-hosted copies of the WOFF2 fonts previously served by Google Fonts. Downloaded
2026-11-15 from fonts.gstatic.com using the requests in the local Lighthouse report.
Outfit and DM Sans are variable fonts; JetBrains Mono is used at weight 400.
Original OFL license files are included for each family, obtained from google/fonts.
Retain the licenses when distributing these assets. No font binaries were modified.
